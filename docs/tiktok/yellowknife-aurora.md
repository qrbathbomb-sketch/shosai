# 撮影パッケージ:「オーロラ観測率が世界一の街」イエローナイフ

前提: `world-record-format.md` のフォーマットに乗せる1本目。尺 60秒 / 9:16。

---

## 0. この企画の弱点と、その処理

真上から見たイエローナイフは**ただの町**で、絵として見るものが無い。
参考動画（東海大浦安高校）はGoogle Earthの映像そのものが中身だったが、この企画はそうならない。
放置すると前半30秒が死に、オーロラ素材まで誰も到達しない。

**処理: Google Earthパートに「なぜ世界一か」を目で見せる仕事をさせる。**

使う事実（これが本編の核）:

> イエローナイフは**北緯62.45度**。オーロラで有名なノルウェーのトロムソは**北緯69.6度**で、
> 700km以上も北にある。それでも観測率はイエローナイフが上。
> 理由は**地磁気の北極がカナダ側に寄っている**から。地理的には南でも、
> **地磁気緯度では約68度**あり、オーロラベルトのほぼ真下に入る。

「北に行くほど見える」という直感を裏切るので、驚きが出る。
地球儀を回して2都市を並べる → 緯度線を見せる → 寄る、という映像の必然性もここから生まれる。

## 2. 台本（そのまま読み上げに投げられる）

```
黒帯タイトル（全編固定）：オーロラ観測率が世界一の街

 1. [0:03] オーロラを見たいなら
           北へ行けばいいと思ってない？
 2. [0:08] こっちがノルウェーのトロムソ
           北緯69度
 3. [0:13] そしてこっちが
           カナダのイエローナイフ
 4. [0:18] 北緯62度
           トロムソより700km以上も南
 5. [0:23] なのにオーロラが見える確率は
           イエローナイフの方が高い
 6. [0:28] 理由は地磁気の北極が
           カナダ側に寄っているから
 7. [0:33] 地理的には南でも
           地磁気緯度は約68度
 8. [0:38] つまりオーロラベルトの
           ほぼ真下にある
 9. [0:42] さらに内陸で乾燥していて
           晴天率が高い
10. [0:46] 湖のほとりで山が無く
           地平線まで見渡せる
11. [0:50] 3泊すれば95%以上の確率で
           これが見られる
           ↑ここでオーロラ実写にカット
12. [0:55] あなたは見に行きたい？
13. [0:58] コメントで教えて🙋
```

**カットの決め手**: 11番の「これが」でオーロラに切り替える。
テロップの文が終わる前に絵を変えると、視聴者の視線がテロップから映像に移る。

## 3. オーロラ実写素材の調達

自分で撮れない以上、ライセンスがはっきりした素材を使う。

| 調達先 | ライセンス | 備考 |
| --- | --- | --- |
| NASA（ISSからのオーロラ タイムラプス） | パブリックドメイン | `images.nasa.gov` で `aurora` 検索。宇宙からの画なので既視感が少ない |
| Pexels / Pixabay | 無料・商用可（要規約確認） | 使い回されている素材が多い。上位の有名クリップは避ける |
| CapCut 素材ライブラリ | アプリ内規約に従う | 手軽だが他の投稿と被りやすい |

**注意**: TikTokで擦られている素材を使うと既視感で伸びが止まる。
NASAのISS映像は「地上から見上げる画」ではなく「宇宙から見下ろす画」なので、
Google Earthで宇宙から寄ってきた流れとも繋がりが良い。

## 4. ファクトチェック済みの数字と、言い方の注意

| 主張 | 扱い |
| --- | --- |
| 北緯62.45度 / 69.6度 | 事実。言い切ってよい |
| 地磁気の北極がカナダ側 → 地磁気緯度 約68度 | 事実。本編の核 |
| 内陸・乾燥で晴天率が高い | 事実 |
| 3泊で95%以上 | **ツアー会社の公表値**。「〜と言われる」を付けるか出典を明示 |
| 「世界一」 | **測定された記録ではなく旅行業界の通称**。`世界一と言われる` に逃がすか、95%の数字を主語にする |

最後の2つが雑だと否定コメントで荒れる。タイトルは
`オーロラ観測率が世界一の街` より `3泊で95%オーロラが見える街` の方が安全で、数字が入るぶん強い。
