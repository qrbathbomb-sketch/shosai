参考動画: TikTok `@jokumap`「日本一ディズニーに近い高校」(9:16 / 576x1024 / 30fps / 本編約62秒 + TikTok書き出しのエンドカード)

## 1. 元動画の分解（何で作られているか）

### 動画ファイルから確認できた事実

| 項目 | 内容 |
| --- | --- |
| 映像素材 | Google Earth のみ。全カット画面下中央に `Google Earth` の帰属表示、冒頭は `Airbus` のクレジットも表示 |
| カメラ | 東京湾の引き（左下にディズニーリゾートが映る画）→ 東海大浦安高校へゆっくりズームイン → 以後は校舎周辺を低速でパン／回転 |
| カット割り | 実質1カット。カットを割らず、ゆっくり動き続けるだけ |
| テキスト | 上部固定の黒帯タイトル（角丸の黒背景＋白太字）＋ 画面中央やや上の白字キャプション（ドロップシャドウ付き） |
| テキスト演出 | 1文字ずつ出るタイプライター。途中フレームに入力キャラクタ（`|`）が写り込む |
| キャプション数 | 約16〜18枚。おおよそ3〜4秒に1枚の入れ替え |
| 音声 | 44.1kHz ステレオ AAC。ナレーション（ヒカキン声）中心 |
| メタデータ | `vid:v1c044g50000da8rifnog65nr8dnd7gg` / `bvc0ot v2.2.1.3`（TikTokサーバ側の再エンコード痕）/ `aigc_label_type:0`（AI生成ラベルなし） |

### 結論：認識はほぼ合っている

- **Google Earth の画面録画がベース** → 確定。ウォーターマークが全カットに出ている。
- **あとから文字入れ** → 確定。映像の動きと無関係に、テキストだけが独立して出入りしている。
- **ヒカキン声** → TikTok公式の「テキスト読み上げ（音声合成）」に**ヒカキンボイスが正式に入っている**ので、外部で用意したものではなく **アプリ内の読み上げ機能で生成された可能性が高い**。つまり「文字入れ→その文字を読み上げさせる」で音声とテロップが同時に出来上がる流れ。

### 唯一はっきりしない点

文字入れが **TikTokアプリ内** か **CapCut** かは、TikTokがサーバ側で再エンコードしているため映像からは断定できない。
ただしタイプライターの入力カーソルが見える点は CapCut の打字機アニメーションの挙動に近い。
どちらでも再現できるので、実作業は「**CapCutで文字入れ＋読み上げ → TikTokに書き出し**」または「**TikTokアプリ内で完結**」のどちらでもよい。
※ ヒカキンボイスを使うなら TikTok / CapCut の読み上げ機能から選ぶ必要がある。

## 2. バズっている理由（フォーマットの構造）

この動画が効いているのは映像の綺麗さではなく、**情報の出し順**。

1. **黒帯タイトルで「何の動画か」を0秒で宣言**（`日本一ディズニーに近い高校`）
2. **引きの画から始めて、ズームで正体に迫る** → 「どこ？」の引っぱりが自然に発生する
3. **数字で距離感を出す**（約2km / 徒歩30分）→ 具体化された瞬間に納得が生まれる
4. **「なぜそうなったか」の背景を入れる**（渋谷から移転 → 8年後にTDL開園）→ ここが保存とコメントを呼ぶ本体
5. **日常のディテール**（最寄りは舞浜駅 / 南口を出たら目の前）→ 自分ごと化
6. **最後に質問して締める**（`あなたはこの高校に通いたい？` → `コメントで教えて🙋`）

**素材が1つ（Google Earthの1カット）しかなくても成立する**のがこのフォーマットの強さ。撮影ゼロで量産できる。

## 3. 「世界一◯◯」版の制作手順

### 素材づくり（10〜15分）

1. Google Earth（ブラウザ版 `earth.google.com` か Google Earth Pro）で対象地点を開く
2. **まず引きの画をつくる**：対象が点にしか見えない高度から開始
3. 画面録画を開始し、**ゆっくり**ズームイン（速いと酔うし、テロップが読めない）
4. 寄り切ったら、対象の周りをゆっくりパン／回転して30〜40秒ぶん稼ぐ
5. 帰属表示（`Google Earth` のウォーターマーク）は**絶対に消さない・隠さない**。元動画も残している
6. PCで録画した場合は9:16にクロップ。対象を画面の**下2/3**に置く（上1/3はテロップ用に空ける）

> 動きに緩急をつけたいなら Google Earth Studio（無償・要申請）でキーフレームを打つと滑らかになるが、まずは手動の画面録画で十分。参考動画も手動の動きに見える。

### 編集（15分）

1. 9:16タイムラインに素材を置く。**尺は50〜65秒**を目安
2. 上部に**黒帯タイトル**を固定で置く（全編出しっぱなし。途中から見た人向け）
   - 例：`世界一短い飛行機の路線`
3. キャプションを**3〜4秒に1枚**、1枚あたり**2行・各行10〜14文字**で置く
4. テキスト演出はタイプライター。フォントは太めのゴシック、白＋薄いドロップシャドウ
5. 各キャプションに**読み上げ（ヒカキンボイス）**を当てる
6. BGMは無し〜極小音量。ナレーションが主役

### 投稿

- キャプション本文に「◯◯編、次はどこ見たい？」を入れてコメント誘導
- ハッシュタグは `#世界一 #地図 #GoogleEarth #雑学` 系＋固有名詞
- **シリーズ名を毎回同じ文言で固定**（例：`世界一シリーズ`）。フォロー理由になる

[0:07-0:12] キャプション2   ：ここは◯◯国の△△
[0:12-0:18] キャプション3   ：（数字で規模を出す：km / m / 分 / 人）

## 7. 注意点

- **Google Earth の帰属表示は消さない**。ウォーターマークを隠したり切り落としたりしない。使い方は Google の利用規約／帰属表示ガイドラインを確認する。
- **ヒカキンボイスなどの著名人ボイスは、一般ユーザーのエンタメ用途を前提に提供されている**。広告案件・商品訴求など営利性のある使い方は規約違反になり得るので、収益化を狙う段階で必ず現行の規約を確認する。判断がつかない場合は通常の合成音声ボイスに差し替える。
- **「世界一」は事実確認が命**。間違えると否定コメントで伸びるが、シリーズの信用は落ちる。1次情報（公式サイト・公的統計）で裏を取り、怪しいものは「世界最大級」に逃がす。
- **同じ構図の使い回しはしない**。地点ごとに引きの高度と寄りの角度を変える。
