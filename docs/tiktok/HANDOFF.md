# ローカルのClaude Codeへの引き継ぎ

このファイルは、Mac上で起動した Claude Code に渡すための作業指示。
クラウド側のセッションは egress が塞がっていて Google Earth に到達できないため、
映像の取得と書き出しはローカルで行う。

## ゴール

TikTok用の **1080x1920 / 30fps / 60秒** の映像素材 `yellowknife.mp4` を作る。
**テロップと音声は入れない**（投稿者が自分でCapCut等で入れる）。

## 人間がやること / Claudeがやること

| 人間 | Claude |
| --- | --- |
| Earth Studio のアクセス申請 | `.esp` プロジェクトファイルの生成 |
| Google アカウントでログイン | `assemble.sh` を回して mp4 に組む |
| Import とレンダリングの実行 | 書き出しフレームの目視確認 |
| | オーロラ実写素材の調達 |

**Earth Studio の UI を Playwright で自動操作しようとしないこと。**
タイムラインとキーフレームパネルは独自UIで、自動化は壊れやすく時間の無駄になる。
`.esp` をインポートさせる方が確実。

## 手順

1. まず人間に Earth Studio（https://earth.google.com/studio/）のアクセス申請と
   ログインを済ませてもらう。
2. 人間に、キーフレームを1つだけ打った空プロジェクトを `.esp` で
   エクスポートしてもらう。**そのJSONスキーマを読んでから**、下の7点の
   キーフレームを埋めた `.esp` を生成する（スキーマを推測で書かない）。
3. 人間が Import → Image Sequence (PNG) で書き出す。
4. `docs/tiktok/capture/assemble.sh` で組む:
   `./assemble.sh <連番PNGのディレクトリ> yellowknife.mp4`
5. 書き出した mp4 から数フレーム抜いて目視確認する。特に:
   - 帰属表示（Google Earth のクレジット）が焼き込まれているか
   - 動きが滑らかか、途中で破綻していないか
   - 1080x1920 になっているか

## カメラのキーフレーム（60秒 = 1800フレーム / 30fps）

| # | Frame | 秒 | Latitude | Longitude | Altitude | Heading | Tilt |
| --- | --- | --- | --- | --- | --- | --- | --- |
| K1 | 0 | 0.0 | 70.0000 | -60.0000 | 12,000,000 m | 0 | 0 |
| K2 | 240 | 8.0 | 68.0000 | -45.0000 | 9,000,000 m | 15 | 0 |
| K3 | 540 | 18.0 | 66.0000 | -48.0000 | 6,000,000 m | 10 | 0 |
| K4 | 840 | 28.0 | 64.0000 | -105.0000 | 1,800,000 m | 0 | 0 |
| K5 | 1140 | 38.0 | 62.8000 | -114.0000 | 250,000 m | 0 | 25 |
| K6 | 1380 | 46.0 | 62.4540 | -114.3718 | 12,000 m | 20 | 45 |
| K7 | 1800 | 60.0 | 62.4540 | -114.3718 | 8,000 m | 35 | 50 |

- 全キーフレームを **Ease In / Ease Out** に。Linear だと動きが機械的になる。
- **帰属表示を切らない**。書き出し設定で必ず有効にする。
- 46秒地点でオーロラ実写にカットする想定。K7まで撮っておいて編集で切る。

## オーロラ実写素材

46秒以降に繋ぐ素材。ライセンスがはっきりしたものだけ使う。

- **NASA**（`images.nasa.gov` で `aurora` 検索）: パブリックドメイン、商用可。
  ISSからの俯瞰映像は既視感が少なく、Earth Studio の宇宙からの寄りとも繋がりが良い。
  ただし NASA ロゴの使用と、NASA による推薦を示唆する表現は不可。
- Pexels / Pixabay: 商用可だが規約変更に注意。上位の有名クリップは擦られているので避ける。
- **CC-BY-SA は使わない**（シェアアライク条件が動画全体に波及しうる）。
